# Low M. - Personal Site

Rewriting popular Python libraries in Rust for next-generation AI infrastructure.

## 特点

- 🎨 酷炫极简设计 - 深色主题，精致动效
- ⚡ Next.js 15 - 快速、现代的 React 框架
- 🎬 GSAP + Framer Motion - 流畅的动画效果
- 📦 真实项目展示 - PyPI 包 + GitHub 贡献
- ♿ 可访问性 - 支持 prefers-reduced-motion

## 技术栈

- **框架**: Next.js 15
- **样式**: Tailwind CSS
- **动画**: GSAP, Framer Motion
- **部署**: Vercel / 任何 Node.js 托管

## 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 启动生产服务器
pnpm start
```

# Low M. - Personal Site

Rewriting popular Python libraries in Rust for next-generation AI infrastructure.

## Features

- 🎨 Cool minimalism - Dark theme with refined motion
- ⚡ Next.js 15 - Fast, modern React framework
- 🎬 GSAP + Framer Motion - Smooth animations
- 📦 Real projects - PyPI packages + GitHub contributions
- ♿ Accessibility - prefers-reduced-motion support

## Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Animation**: GSAP, Framer Motion
- **Deployment**: Vercel / any Node.js hosting

## Development

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```
